# 自动 PR Stack：文案审阅清单

本清单对应实际提示。`{变量}` 在运行时替换，箭头从下层 PR 指向上层 PR。状态展示在 Piper Progress，恢复记录复用已有 Bot 评论。

## 主要状态

| 场景 | 文案 |
| --- | --- |
| 正在创建或追加 | `正在建立pr Stack` |
| 等待建立完成 | `正在等待stack建立` |
| GitHub 拒绝操作 | `Stack失败：github未接受` |
| 操作暂停 | `Stack 已暂停：{原因}` |
| 已管理的 Stack 被修改 | `已管理的 Stack 被修改，已暂停自动操作，可通过 stack.enabled关闭自动管理` |
| 已有手动 Stack | `Stack暂停：监测到已有手动Stack` |

## 等待与核验

| 场景 | 文案 |
| --- | --- |
| PR 或依赖图正在更新 | `正在等待PR或依赖图更新` |
| Stack 信息同步中 | `正在等待Stack同步` |
| HEAD 同步中 | `正在等待HEAD同步` |
| 无法核实 Stack 状态 | `Stack暂停：状态无法核实` |
| 无法读取 Stack | `Stack失败：无法读取github Stack` |
| 无法读取目标或历史 | `Stack失败：目标分支或提交历史不可读` |
| 最终目标不明确 | `Stack暂停：最终目标分支不明确` |
| 同一源分支有多个 PR | `Stack暂停：同一分支存在多个 PR` |
| 源分支丢失 | `Stack暂停：源分支已删除或无法读取` |
| Stack 更新或下层关闭 | `Stack暂停：状态未同步或下层 PR 已关闭` |
| 多个 PR 指向相同 HEAD | `Stack暂停：多个 PR 指向同一 HEAD` |
| 共享未合入历史且 HEAD 分叉 | `Stack暂停：共享未合入历史，HEAD 已分叉` |
| 祖先关系不明确 | `Stack暂停：祖先关系不明确` |
| 多个直接父节点 | `Stack暂停：存在多个直接父 PR` |
| Base 与父节点不符 | `Stack暂停：Base 与直接父 PR 不一致` |
| 依赖图分叉 | `Stack暂停：依赖图分叉` |
| 超过候选范围 | `Stack暂停：待核验 PR 超过 20 条` |
| PR 列表异常 | `Stack暂停：PR 列表不完整或重复` |
| PR 属于多个 Stack | `Stack暂停：PR 属于多个 Stack` |
| 恢复回执异常 | `Stack暂停：恢复回执不一致` |
| 合并前依赖已变化 | `Stack暂停：HEAD、Base 或依赖已变化` |

## 暂停原因

以下原因通过 `Stack 已暂停：{原因}` 展示。已有完整状态文案的回执直接显示原文，不重复添加前缀。

| 场景 | 原因 |
| --- | --- |
| 依赖图改变 | `依赖图已变化` |
| 保存的快照失效 | `HEAD、Base 或依赖已变化` |
| 合并结果待确认 | `下层 PR 合并结果未确认` |
| 涉及多个 Stack | `涉及多个 Stack` |
| PR 即时状态改变 | `PR 已变化` |
| 源分支 HEAD 待同步 | `源分支 HEAD 未同步` |
| PR 冲突 | `PR 存在冲突` |
| Base 链未就绪 | `Base 链未就绪` |
| 恢复计划异常 | `恢复计划不一致` |

## 关系展示

| 位置 | 文案或模板 |
| --- | --- |
| 检查项名称 | `Stack 依赖` |
| 依赖链 | `{#下层 → #上层} · 最终目标 {分支}` |
| 没有完整依赖链时 | `自动 Stack` |
| 原生 Stack 信息 | `Stack #{编号} · 位置 {序号}/{总数} · 最终目标 {分支} · 直接父分支 {分支}` |
| 下层尚未合并 | `等待下层 {#编号}` |
| 合并请求受阻 | `请先合并下层 PR：{#编号}。` |
| 无下层阻塞时 | `可独立集成` |

多个 PR 编号用 `、` 分隔；有暂停原因时不显示“可独立集成”。

Progress 示例：

```text
Stack 依赖：#72 → #74 · 最终目标 dev；正在建立pr Stack；等待下层 #72
Stack 依赖：#72 → #74 · 最终目标 dev；正在等待stack建立；等待下层 #72
Stack 依赖：#72 → #74 · 最终目标 dev；Stack 已暂停：PR 存在冲突；等待下层 #72
```

## 内部诊断

以下文本用于日志或队列重试，不单独新增评论。Compare 异常会映射为前述核验失败提示。

| 场景 | 文案 |
| --- | --- |
| Compare 响应异常 | `Stack失败：Compare 祖先信息不一致` |
| 等待冲突检查 | `正在等待Stack冲突检查` |
| 等待 Stack 返回 | `正在等待Stack同步` |

配置说明见 [README：自动 Stack](../README.md#自动-stack)。
